# BiucingCLI 0.9.0 Plan

Target version: `0.9.0`

## Theme

`0.9.0` is the release and generator-core hardening release. It makes the installed distribution, rather than a source checkout, the primary product boundary.

## Goals

- Bundle all seven templates in wheel and source-distribution artifacts.
- Resolve and normalize user inputs before computing derived values.
- Convert expected template and filesystem failures into stable CLI errors.
- Prevent failed generation from leaving partial target directories.
- Verify the installed wheel outside the source tree across supported Python versions.

## Delivery Tracks

### Package-owned resources

- Move template metadata and starter files under `src/biucingcli/template_data`.
- Declare the build backend, source layout, and package-data behavior explicitly.
- Verify hidden files and binary resources in both wheel and source distributions.

### Deterministic input pipeline

- Apply CLI-over-`--set` precedence before resolution.
- Normalize provided values once.
- Resolve defaults and `default_from` values.
- Compute Apple, Android, and Microservice derived values only from resolved values.
- Validate the final declared-variable set before creating files.

### Stable failure boundary

- Use domain errors for unknown templates, invalid metadata, conflicts, and generation failures.
- Reserve exit code `2` for user-correctable request or filesystem conflicts.
- Reserve exit code `1` for invalid bundled template metadata and validation failures.
- Keep unexpected programming failures visible during development.

### Artifact verification

- Build wheel and source distributions in a temporary location.
- Install the wheel in a clean virtual environment.
- Run the installed CLI from outside the repository.
- Validate and generate all seven templates without platform SDK builds.
- Run the gate on Python 3.11 through 3.14 in CI.

## Non-goals

- Adding templates or changing the intended starter stacks.
- Introducing an external templating engine.
- Dynamically generating every dedicated CLI flag from metadata.
- Running Xcode, Android, HarmonyOS, Docker, or browser builds in the package smoke gate.

## Release Bar

```bash
python3 -m unittest discover -s tests
uvx ruff==0.16.6 check --select E4,E7,E9,F src tests scripts
PYTHONPATH=src python3 -m biucingcli.cli validate
./scripts/verify-distribution
git diff --check
```

The release is blocked if an installed wheel cannot list, validate, and generate all seven bundled templates from outside the source repository.
