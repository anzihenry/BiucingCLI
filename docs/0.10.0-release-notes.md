# BiucingCLI 0.10.0

0.10.0 expands the generated projects across frontend rendering, native binary
components and backend delivery, with stricter generation and package verification.

## Highlights

- Frontend: CSR, SSG and SSR presets with shared React Router tooling, production
  images, browser checks and installed-package acceptance.
- Apple: iOS, macOS, watchOS and tvOS shells consuming versioned static XCFrameworks,
  SafeDI constructor graphs and a shared C++20 core.
- Android: mobile, Wear OS and TV shells, Maven AAR components, Dagger graphs and
  JNI sessions. HarmonyOS adds binary HAR components and a Node-API bridge.
- Backend: Docker-first development, validated configuration, health/admin endpoints,
  graceful shutdown, PostgreSQL migrations, Web OIDC sessions, Micro mTLS identities,
  bounded outbound calls and OpenTelemetry integration.
- Delivery: hardened production Compose, signed-image verification, migration and
  rollback tools, isolated backup/restore checks, plus Kubernetes/Kustomize references.
- CLI: versioned JSON results/errors, stronger input escaping and validation,
  deterministic resource variants, and exact wheel/sdist resource verification.

## Compatibility changes

- `microservice` is renamed to `micro-service`; the old name is removed.
- `--dependency-store` / `dependency_store` is removed. Select `--database` and
  `--cache` independently. Micro defaults to neither; Web requires PostgreSQL.
- The Web in-memory user CRUD example is removed. Generated backends provide general
  infrastructure and authentication foundations for application-specific APIs.
- Apple projects require Swift 6.4 or later. Frontend projects use the toolchain
  versions pinned in their generated files.

Existing generated projects are not migrated automatically. Review generated output
and the architecture guides before adopting the new templates in an existing project.

## Install

```sh
uv tool install biucingcli==0.10.0
# For an existing uv tool installation:
uv tool upgrade biucingcli
biucing --version
biucing list
```

## Verification boundaries

The release uses core/platform tests, installed wheel/sdist checks and generated
frontend/backend verification. Native build and simulator evidence is documented in
this repository; device coverage varies by platform. HarmonyOS real-device and
signed-delivery acceptance remain separate gates.

Kubernetes files are reference deployments. **B27 real multi-zone high-availability
acceptance is on hold**; this release does not claim measured production HA, RPO or
RTO. See the [release verification record](0.10.0-release-prep.md) for evidence.
