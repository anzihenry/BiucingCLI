# BiucingCLI 0.8.0 Release Prep

Target version: `0.8.0`

Verification date: `2026-08-31`

## Scope

`0.8.0` is a cross-template hardening release. It covers validated generator inputs, a shared Make command contract, production browser testing, backend lifecycle behavior, deterministic worker retries, native credential protection, and native signing/artifact verification.

Human-readable dry-run, JSON plan, non-interactive generation, and rendered `make help` smoke checks also passed for one Frontend and one Web Service project.

The automated suite covers rendering all seven starters, the common Make command contract, invalid-input rejection, generated Go runtime tests, Frontend production-browser wiring, Apple release identity checks, Android supply-chain and bundle verification, and HarmonyOS lock/signing/artifact verification.

## Known Boundaries

- No real store upload is performed without Apple, Google Play, or AppGallery credentials and application records.
- Native signing and artifact checks use deterministic fixtures in the repo suite for this release run; the existing `0.7.0` workstation real-build evidence remains the latest SDK-backed native build record.
- Production browser and container workflows are covered by their generated configuration and regression tests; publication does not require starting long-lived local services.
