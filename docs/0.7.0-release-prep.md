# BiucingCLI 0.7.0 Release Prep

Target version: `0.7.0`

Verification date: `2026-08-01`

## Scope

`0.7.0` completes the native-template pre-distribution surface. It adds Apple and Android delivery automation, Android signing and App Bundle checks, and HarmonyOS local signing/release packaging. It also records fresh real-build evidence for all three native templates.

```bash
PYTHONPATH=src python3 -m biucingcli.cli validate

```

## Release Delivery Boundaries

- Apple archive, TestFlight, and App Store Connect delivery require `APP_STORE_CONNECT_API_KEY_PATH`, `MATCH_GIT_URL`, a development team, and a configured App Store Connect application.
- Android Google Play delivery requires `GOOGLE_PLAY_SERVICE_ACCOUNT_JSON`, release signing material, and a configured Google Play application.
- HarmonyOS validates local release signing and creates a signed HAP when local signing material is present. AppGallery or enterprise upload remains a product-specific handoff.

None of these account-dependent delivery steps were represented as completed in this release evidence.
