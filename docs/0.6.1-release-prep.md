# BiucingCLI 0.6.1 Release Prep

This note records the release-prep evidence for the `0.6.1` worktree isolation hardening release.

Target version: `0.6.1`
Verification date: `2026-07-20`
Evidence directory: `/tmp/biucing-061-phase-g.qXARfS`

## Scope

`0.6.1` hardens the worktree-ready behavior shipped in `0.6.0`.

The release focuses on:

- one shared `WORKTREE_ROOT`, `WORKTREE_LABEL`, `WORKTREE_ID`, and `WORKTREE_SLUG` identity model across all seven templates;
- Docker-first port conflict advice before service startup;
- generated `make worktree-compose-config` diagnostics for Compose templates;
- native evidence labels that separate `static`, `doctor`, and `real-build` proof;
- an explicit HarmonyOS debug identity boundary with read-only diagnostics and deferred bundle rewriting.

## Known Limitations

- This release-prep run did not start Docker containers; it rendered Compose config for non-invasive worktree proof.
- Native evidence in this run is `static` plus generated doctor evidence, not SDK-backed real-build proof.
- HarmonyOS per-worktree bundle rewriting remains deferred until the DevEco/hvigor app metadata hook is verified on a configured workstation.

## Release Operation

Formal release steps:

```bash
git commit -m "chore: release 0.6.1"
git tag -a v0.6.1 -m "Release 0.6.1"
git push origin main
git push origin v0.6.1
gh release create v0.6.1 --title "BiucingCLI 0.6.1" --notes-file /tmp/biucing-0.6.1-release-notes.md
```

The release is ready once the version-surface commit is pushed, the annotated tag is present on GitHub, and the GitHub Release points at `v0.6.1`.
