# BiucingCLI 0.7.0

`0.7.0` makes the Apple, Android, and HarmonyOS starters ready for a more disciplined pre-distribution workflow.

## Highlights

- Apple templates now carry Fastlane archive, TestFlight, and App Store Connect delivery lanes, with explicit signing and App Store Connect preflight requirements.
- Android templates now verify release keystores, produce and validate release App Bundles, and provide Fastlane lanes for Google Play internal testing and production draft delivery.
- HarmonyOS templates now provide a local signing preflight and a release HAP build workflow that restores the source build profile after the build.
- Native validation evidence is fresh and concrete: Apple builds and tests on iOS and macOS, Android lint/unit/APK/AAB/UI verification on an emulator, and HarmonyOS lint/test/HAP verification on a configured DevEco workstation.

## Important Boundary

The starters automate the local and credentialed delivery steps, but this release does not claim a real store submission. Apple App Store Connect, Google Play, and AppGallery/enterprise delivery still require each product's own account, signing material, application record, metadata, and review configuration.
